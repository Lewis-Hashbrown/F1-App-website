# Google Sites Setup Instructions for F1 Widget 2025 Website

## Step-by-Step Setup Guide

### 1. Access Google Sites
- Go to [sites.google.com](https://sites.google.com)
- Sign in with your Google account
- Click "Create" or "+" to start a new site

### 2. Choose Template
- Select "Blank" template for full customization
- Or choose a business/app template to modify

### 3. Site Settings
- **Site Name:** F1 Widget 2025
- **URL:** Choose something like `f1widget2025` or `f1-schedule-widget`

### 4. Page Structure Setup

#### Main Navigation:
1. **Home** (Main page)
2. **Privacy Policy** (Separate page)
3. **Contact** (Optional separate page)

### 5. Home Page Setup

#### Header Section:
1. **Insert → Image** - Add F1 racing image or logo
2. **Insert → Text Box** - Add title: "F1 Widget 2025"
3. **Insert → Text Box** - Add subtitle: "Never Miss a Formula 1 Session Again"

#### Main Content Areas:
1. **About Section** - Copy from `main-page-content.md`
2. **Features Section** - Use the 6 key features listed
3. **Download Section** - Placeholder for Play Store link
4. **Privacy Summary** - Brief overview with link to privacy page
5. **Contact Section** - Developer information

### 6. Privacy Policy Page Setup
1. Click **Pages** in the editor
2. Click **+ Add Page**
3. Name it "Privacy Policy"
4. Copy content from `privacy-policy-content.md`
5. Format with headers and bullet points

### 7. Design Customization

#### Theme Settings:
- **Primary Color:** #E10600 (F1 Red)
- **Font:** Choose modern font like "Open Sans" or "Roboto"
- **Layout:** Clean, professional layout

#### Header:
- Add banner image (F1 racing scene)
- Make title prominent with F1 red color

#### Content Formatting:
- Use **Heading 1** for main sections
- Use **Heading 2** for subsections  
- Use **Bullet Lists** for features
- Use **Bold** for important text
- Use **Text Color** (#E10600) for F1 branding

### 8. Add Interactive Elements

#### Buttons:
- **Download Button** - Style with red background (#E10600)
- **Privacy Policy Link** - Link to privacy page
- **Buy Me a Coffee Button** - External link

#### Images to Add:
1. **Header Banner** - F1 racing image or track
2. **Phone Mockup** - Android phone with widget (if available)
3. **Google Play Badge** - For download section
4. **F1 Schedule Screenshot** - Visual of race times

### 9. Mobile Optimization
- Preview on mobile using Google Sites preview
- Ensure text is readable on small screens
- Check that buttons are easily tappable

### 10. SEO Settings
1. Click **Settings** (gear icon)
2. **SEO → Page Title:** "F1 Widget 2025 - Formula 1 Schedule Widget for Android"
3. **Description:** "Never miss F1 sessions with our Android widget. Shows FP1, FP2, FP3, Qualifying, Race times in your timezone."
4. **Custom URL:** Set clean URL like "f1widget2025"

### 11. Publishing
1. Click **Publish** button (top right)
2. Choose visibility: **Public** (so anyone can find it)
3. Your site will be available at: `sites.google.com/view/yourusername/f1widget2025`

### 12. Custom Domain (Optional)
- In Settings → Custom Domain
- Connect your own domain if you have one
- Requires domain ownership verification

3. **Mobile First** - Always check mobile preview
4. **Update Regularly** - Keep content fresh and current
5. **Link Building** - Add relevant external links (Buy Me a Coffee, etc.)
