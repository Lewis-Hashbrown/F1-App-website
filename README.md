# F1 Widget 2025 Website

This website promotes the F1 Widget 2025 Android app - a Formula 1 schedule widget that displays race weekend session times directly on Android home screens.

## Files Structure

- `index.html` - Main landing page with app features and download information
- `privacy-policy.html` - Comprehensive privacy policy for the app
- `README.md` - This documentation file

## Features Highlighted

### Main Landing Page (`index.html`)
- **App Overview**: Complete description of F1 Widget 2025 functionality
- **Feature Showcase**: 
  - Complete session schedule (FP1, FP2, FP3, Qualifying, Race, Sprint)
  - Automatic timezone conversion
  - 2025 F1 season calendar
  - Live updates
  - Multiple widget sizes
  - Battery optimization
- **Download Section**: Ready for Google Play Store link
- **Privacy Summary**: Key privacy points with link to full policy
